# 04 · 真实规则与模型实验

## 核心问题

用户提出关键问题：**真实的知识是否成为作品中可以操作和发现的规则，而不只是换上奇幻名字？**

## 回答：是的，现在做到了

### 三类硬约束

| 约束 | 实现 |
|---|---|
| **可操作** | 36 对碰撞里 9 对内嵌可拖动小实验，每个都有单一可拖参数、结果实时变化 |
| **可发现** | 频率破译纯频率只能还原约三~四成，必须再上词典回溯才能到 100%；营养级联需移出狐狸后推演 150 代 |
| **有边界** | 每个结果卡最后一行都是「边界」（无摩擦市场假设、多重比较假阳性等） |

### 8 个小实验

| 实验 | 核心操作 |
|---|---|
| 分层抽样 | Neyman 最优分配 |
| 功效与样本量 | 检验功效曲线与 80% 门槛 |
| 信号检测论 | d′ 与 β 此消彼长 |
| 感官阈限（阶梯法） | 3 下 1 上自动收敛到 70.7% 阈限 |
| 一维扩散 | 浓度剖面按解析解展宽 |
| 最小方差套保 | 组合方差下降并定位最优比率 |
| 分类阈值与混淆矩阵 | F1 在何处最大 |
| 过拟合演示 | 训练误差 vs 验证误差分叉 |

## 实现思路

1. 先给每个专业标注「方法 / 对象 / 领域」
2. 让「碰撞」= 两个专业的方法互相作用
3. 碰撞不是随机拼词，而是「谁给工具、谁给问题」的真实分工
