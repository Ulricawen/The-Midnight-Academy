# ai-logs/ · AI 对话记录

## 应包含的内容

请从 AI 编程工具（Trae / 其他）导出开发对话后放入本目录，建议节选以下关键环节：

| 文件（建议命名） | 对应开发环节 | 印证的 AI_USAGE 条目 |
|---|---|---|
| `01-选题与结构.md` | 四道赛题对比、选定 The Midnight Academy、3 学派 + 3 交汇结构 | §1 构思与选题 |
| `02-破译算法迭代.md` | 纯频率 → 频率初值 + 词典回溯的多轮原型与实测 | §1 核心算法 |
| `03-生态模型调参.md` | 三物种方程参数仿真与失真参数剔除 | §1 模型调参 |
| `04-真实信息核对.md` | 官网院系/科研平台信息核对与页面标注 | §1 知识建模、§3 素材 |

## 导出方式

- Trae：会话面板 → 导出/分享对话 → 保存为 Markdown 后重命名放入本目录。
- 节选即可，无需完整逐字记录；能体现「团队的思考与判断」（规则原文：评审关注团队的思考与判断，而不是代码量）为宜。
