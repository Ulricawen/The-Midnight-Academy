# 03 · 分页结构与旅程化改版

## 问题诊断

- 原页面是多页拼接的长网页，缺乏嵌套结构
- 用户期望：像学校官网一样分页，有嵌套、有导航

## 核心改动

### 分页结构
- 顶部固定站点导航：午夜学园 + 学派大厅 / 交汇圣坛 / 碰撞熔炉 / 学派手账
- hash 路由（`#/schools/cipher` 等 11 条），浏览器前进/后退可用
- 列表页 → 子页嵌套：学派大厅列出 3 张学派卡片，点进去是实验页，顶部有面包屑返回

### 废话文案清理
- 删除「本作品以北师香港浸会大学真实的学院…为骨架」
- 删除「原型：北师港浸大 · 博文雅志，真知笃行」
- 删除页脚「BNBU / 学校官网」等全部校名表述

### 旅程化设计
- 序章（像素月亮 + 星图）→ 8 站线性解锁
- 星图标注 已完成 / 下一站 / 可进入 / 未解锁
- 未解锁站点强行拦回

### 视觉与字体精简
- 像素/马赛克风：方角硬边框、`image-rendering:pixelated`、4px 网格 + 棋盘格抖色
- 字体精简：全站一套等宽字体族（ui-monospace 系），标题正文同族

## Bug 修复
- 密码试炼「用钥匙解封」输出 undefined
- 碰撞结果「前往查看」直达对应子页

## 验证
- 真机浏览器 9 步全过（分页切换、面包屑、画布重排、拖拽碰撞+弹窗+跳转）
- 控制台 0 报错
