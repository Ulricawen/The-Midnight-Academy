# The Midnight Academy · 午夜学园

**BNBU Programming Contest 2026 · AI Track · 选题：The Midnight Academy（学习与知识）**

> 真实的知识如何成为可玩的魔法规则？
> 只在梦中开启的学院：每个学科是一个古老学派，每一种魔法都来自真实的规则——可以操作它、试验它、看见它的边界；而最惊人的魔法，出现在学派相遇的地方。

---

## 1. 如何运行（零环境依赖）

## 2. 作品结构与核心功能

| 区块 | 内容 | 文件位置 |
|---|---|---|
| 学派大厅（3 个试炼） | 密码：关键词单表替换；统计：正态抽样与 95% 置信区间直方图；生态：草-兔-狐食物链 150 代推演（可移出任一物种观察营养级联） | `index.html` 学派大厅 section |
| 交汇圣坛（3 个组合实验） | 频率之眼（密码×统计）、标志重捕（统计×生态）、基因封印 eDNA（密码×生态） | `index.html` 交汇圣坛 section |
| 学派手账 | 每条魔法的「真实知识来源」与「局限（魔法的边界）」对照表 | `index.html` 学派手账 section |
| 掌握度进度 | 6 个实验各有可验证的完成状态，顶部进度条 `n / 6` | `index.html` 页首 progress 栏 |

**扣题点（对应赛题评审口径）**：真实的知识不是换上奇幻名字，而是作品中**可以操作和发现的规则**——
- 单表替换的「频率泄露」是操作出来的：纯频率法只还原约四成，换用「频率初值 + 单词模式词典回溯」两步法可达 100%（内置 20k 开源词表，毫秒级确定性求解）；
- 置信区间随样本收敛、真实均值是否落入区间是抽样抽出来的；
- 营养级联是把狐狸移出梦境后推演出来的；
- 三个交汇实验**必须组合两个学科才能完成**，单一学科无法实现。

## 4. 与最相近已有产品的差异

**① Cryptii（cryptii.com）等交互式密码/编码工具**
Cryptii 展示各类编码与密码（含单表替换、频率直方图），是"查看器"；本作品的频率分析是**一条完整的确定性破译流水线**（频率初值 → 单词模式词典回溯 → 手动修正映射），可对随机密文达到 100% 还原并给出还原度数值，且它只是三个交汇实验之一——密码学必须与统计学、生态学相遇才能解锁后续内容。

**② PhET Interactive Simulations（如 Predator-Prey / Natural Selection）**
PhET 每个仿真覆盖单一学科、演示单一现象；本作品的差异在于**跨学派组合**：三个交汇实验分别需要两两学科联手（频率之眼 / 标志重捕 / eDNA 条形码），并为每条规则同时给出「真实知识来源」与「魔法的边界」双栏说明，还把实验锚定到本校真实院系与重点实验室，形成"知识 → 规则 → 边界 → 学科交叉"的完整闭环。

## 5. 核心设计决策与技术取舍

1. **单文件零依赖 vs. 框架与构建**：为保证现场演示与离线评阅零环境风险，放弃 React/Vite，手写原生 JS + Canvas；代价是没有组件复用，收益是双击即运行、断网可玩。
2. **破译算法两步走**：纯频率在短文本上只能还原约 35%（统计样本不足）；升级为「频率排序初值 + 按单词模式剪枝的词典回溯」，确定性求解、无随机抖动、实测 3 段密文 100% 还原（毫秒级）。取舍：内置 20k 词表增加体积，换来离线可用。
3. **生态模型选型**：三物种耦合逻辑斯蒂方程，经多组参数仿真调优——移除狐狸可见清晰的营养级联，且 150 代后狐群稳定在个位数~十余只，不触顶失真；刻意不做更复杂模型，保持"演示方向而非精确预言"的边界诚实。
4. **可复现的随机性**：正态抽样用 Box-Muller 生成；画布统一使用 CSS 像素坐标绘制，规避高 DPR 屏参考线偏移。
5. **演示动线**：顶部「掌握度 n / 6」把 6 个实验组织成评委可上手的清单，每一步完成都有即时反馈。

## 6. 模拟数据声明

- **模拟**：标志重捕的池塘真实鱼数、eDNA 三段序列（COI 条形码为演示模拟，真实比对需基因库）、统计抽样总体（"梦兽身高" N(160, 15²)）均为虚构/模拟数据。
- **真实**：页面中的院系、专业、学科建设与科研平台信息来自学校官网公开资料。
- 作品不收集任何个人信息，无网络请求、无追踪。
