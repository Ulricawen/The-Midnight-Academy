**BNBU Programming Contest 2026 · AI Track · 选题：The Midnight Academy（学习与知识）**

> 真实的知识如何成为可玩的魔法规则？

## 2. 体验动线：一段循序渐进的旅程

整站从「一页到底」重构为**有入口、有推进感的旅程**：从序章开始，沿地图路线一站一站走进去，完成一站才点亮下一站；每次进入/离开关卡都有**云雾从两侧合拢、再从中间散开**的转场（拨云见日）。

- **序章（`#/`）**：像素魔法城堡 + **路线地图**——8 个站点由 9 条路线串成，前三站是主干，第四站「碰撞熔炉」后**分出三条交汇支路**（频率之眼 / 标志重捕 / 基因封印可任选顺序），最后汇入终章「学派手账」。已解锁的路线点亮为金色实线，未解锁为暗色虚线；节点标注状态（`已完成` / `下一站` / `可进入` / `未解锁`），未解锁的站点点击会被拦下并提示。
- **关卡底部导航**：每个关卡页底部有「🗺 回到地图」和「下一站 · ▶」按钮——完成后下一站按钮自动点亮，未完成时显示为不可点的「完成本关后解锁下一站」。
- **顶部「学识 n / 6」**：6 个可验证实验的完成进度，芯片随完成点亮，刷新后由 `localStorage` 恢复。
- **旁白打字机**：进入每一站时逐字给出一句引导语，把 8 个站点串成一条叙事线。
- **八站顺序**：封印之语 → 命运抽样 → 万物之网 → 碰撞熔炉 → ｛频率之眼 / 标志重捕 / 基因封印 三选序｝→ 学派手账。

| # | 站点 | 学科 | 核心交互 |
|---|---|---|---|
| 1 | 封印之语 | 密码 | 输入关键词生成单表替换密文，再用钥匙还原 |

| 3 | 万物之网 | 生命 | 草-兔-狐 150 代推演，可移出任一物种看营养级联 |

| 5 | 频率之眼 | 密码 × 统计 | 频率初值 + 词典回溯两步破译，可手动修正映射 |
| 6 | 标志重捕 | 统计 × 生命 | 一网标记、二网重捕，估计隐藏种群数量 |

## 3. 碰撞熔炉：理工科技学院 4 系 9 专业的 36 对碰撞

聚焦**理工科技学院**，取其 4 个系、9 个本科专业：

| 系 | 专业 |
|---|---|
| 数学科学系 | 应用数学、金融数学 |
| 统计与数据科学系 | 统计学、数据科学 |
| 计算机科学系 | 人工智能、计算机科学与技术 |
| 生命科学系 | 环境科学、食品科学与工程、应用心理学 |

9 个专业两两组合共 C(9,2) = **36 对**，**逐对手写**真实的学科交叉内容，而非模板化填空。每一对都给出一张结果卡：

- **火花名**：这次交叉得到的技法/概念；
- **交叉方式**：两个专业各自贡献什么、为什么缺一不可；
- **真实案例**：现实科研与工业中的对应做法（如 Black-Scholes 定价、Neyman 分配、LASSO 特征筛选、近红外无损检测）；
- **边界**：这条交叉的局限——它在哪里会失效（如无摩擦市场假设、多重比较假阳性、模型迁移需重新标定）。

**玩法**：画布上是 9 个随物理漂浮的**像素方块泡泡**（按系配色）。把一个泡泡**拖到另一个上松手**，或**先点一个再点另一个**，即触发碰撞——像素火花与方形冲击波扩散，0.5 秒后弹出结果卡。已碰撞的组合收进下方**法术卡册**，进度 `n / 36` 持久化，并可按系列或「已合成 / 未合成」筛选。

## 4. 八条可以亲手玩的真实规则（内嵌小实验）

36 对碰撞中有 **9 对**内嵌了可拖动的小实验，共覆盖 **8 个不同的真实模型**。每个小实验都在结果卡里一键进入：

| 小实验 | 出处（碰撞对） | 你亲手操作的是什么 |
|---|---|---|
| 分层抽样 | 最优抽样 / 监测布点 | 拖动分配旋钮，看合并估计方差如何变化，找出 Neyman 最优分配 |
| 功效与样本量 | 心理统计 | 拖动 n 与效应量 d，实时看检验功效曲线与 80% 门槛 |
| 信号检测论 | 认知建模 | 拖动判定标准，看命中率、虚报率、d′ 与 β 此消彼长 |
| 感官阈限（阶梯法） | 感官评价 | 逐轮判断哪杯不同，3 下 1 上阶梯自动收敛到 70.7% 阈限 |
| 一维扩散 | 扩散方程 | 拖动扩散系数与时间，看浓度剖面按解析解展宽 |
| 最小方差套保 | 原料套保 | 拖动套保比率，看组合方差下降并定位最优比率 |
| 分类阈值与混淆矩阵 | 光谱快检 | 滑动阈值，看漏检与误报互换、F1 在何处最大 |
| 过拟合演示 | 模型评估 | 提高多项式阶数，看训练误差一直降、验证误差先降后升 |

## 5. 扣题点（对应赛题评审口径）

真实的知识不是换上奇幻名字，而是作品中**可以操作、可以发现、可以证伪的规则**：

- 单表替换的「频率泄露」是**操作出来**的：纯频率法只还原约三~四成，换用「频率初值 + 单词模式词典回溯」两步法可达 100%（内置 20k 开源词表，毫秒级确定性求解）；
- 置信区间随样本收敛、真实均值是否落入区间，是**抽样抽出来**的；
- 营养级联是把狐狸**移出梦境后推演**出来的；
- 每个小实验都有一条可拖动的物理/统计量，结果随参数**实时变化且可验证**；
- 36 对碰撞**逐对手写**交叉方式、真实案例与边界——把「学科交叉」从口号变成可查证的具体做法；
- 三个交汇站点（频率之眼 / 标志重捕 / 基因封印）**必须组合两个学科才能完成**，单一学科无法实现。

## 7. 与最相近已有产品的差异

**① Cryptii（cryptii.com）等交互式密码/编码工具**
Cryptii 展示各类编码与密码（含单表替换、频率直方图），是"查看器"；本作品的频率分析是**一条完整的确定性破译流水线**（频率初值 → 单词模式词典回溯 → 手动修正映射），可对随机密文达到 100% 还原并给出还原度数值，且它只是三个交汇站点之一——密码学必须与统计学、生命科学相遇才能解锁后续内容。

**② PhET Interactive Simulations（如 Predator-Prey / Natural Selection）**
PhET 每个仿真覆盖单一学科、演示单一现象；本作品的差异在于**跨专业组合**：三个交汇站点分别需要两两学科联手（频率之眼 / 标志重捕 / eDNA 条形码），并把 36 组专业交叉逐条给出「交叉方式 / 真实案例 / 边界」三栏说明，还锚定到真实院系与重点实验室，形成"知识 → 规则 → 边界 → 学科交叉"的完整闭环。

## 8. 视觉与交互风格：像素 / 马赛克

- **像素化**：等宽字体 + 方角硬边框 + 位移投影；画布统一使用 `image-rendering:pixelated` 关闭平滑。
- **像素魔法城堡**：序章主视觉与顶栏小 logo 都是一座多色像素城堡（蓝石塔楼、粉色尖顶、金色灯火窗、三色旗），分别由 Canvas 逐格绘制与内联 SVG rect 拼出。
- **马赛克与抖色（dither）**：专业方块泡泡按 4px 网格绘制、边缘以棋盘格抖色消隐；火花粒子是方形块，冲击波是逐格放大的方框；云雾转场面板也叠了马赛克纹理。
- **复古又现代**：扫描线叠层（`body::after`）+ 细十字网格底纹；金色/紫/青/绿四色对应四个系。
- **字体精简**：全站只用 ui-monospace / Menlo / Consolas 一套等宽字体族，中文回退到 PingFang SC / 微软雅黑，标题与正文同一族——不再堆叠多套字体。
- 全部由纯 CSS + Canvas + 内联 SVG 实现，无外部字体、无图片素材、无第三方库。

## 9. 核心设计决策与技术取舍

1. **单文件零依赖 vs. 框架与构建**：为保证现场演示与离线评阅零环境风险，放弃 React/Vite，手写原生 JS + Canvas；代价是没有组件复用，收益是双击即运行、断网可玩。
2. **破译算法两步走**：纯频率在短文本上只能还原约 35%（统计样本不足）；升级为「频率排序初值 + 按单词模式剪枝的词典回溯」，确定性求解、无随机抖动、实测 3 段密文 100% 还原（毫秒级）。取舍：内置 20k 词表增加体积，换来离线可用。
3. **生态模型选型**：三物种耦合逻辑斯蒂方程，经多组参数仿真调优——移除狐狸可见清晰的营养级联，且 150 代后狐群稳定在个位数~十余只，不触顶失真；刻意不做更复杂模型，保持"演示方向而非精确预言"的边界诚实。
4. **可复现的随机性**：正态抽样用 Box-Muller 生成；画布统一按 CSS 像素坐标绘制，规避高 DPR 屏参考线偏移。
5. **旅程化 + 路线分叉解锁**：用「带路线与分叉的地图」替代平铺目录——主干推进、交汇支路任选顺序、完成点亮路线；配合云雾转场与旁白打字机，让评审有明确的推进动线；未解锁站点强制拦回，避免跳读。
6. **36 对逐对手写，而非规则生成**：聚焦到理工科技学院 9 专业后，组合数降到 36，规模允许逐对手写交叉方式 / 真实案例 / 边界——内容可信、彼此不雷同，且便于为其中 9 对挂上真实模型小实验。
7. **小实验选型**：8 个模型都满足「有单一可拖动参数、结果可实时验证、有明确边界」三条标准，避免做成只会播放的动画。
8. **像素风的实现取舍**：不引入像素字体或美术资源，改用「等宽字体 + 方角 + 抖色 + 扫描线 + 像素画布」在纯代码里营造复古现代感，守住单文件与离线约束。
9. **交互做减法**：删掉页内所有金色标注块与长段真实映射说明，真实锚定收进结果卡与手账；移除多套字体与侧边圆点导航，每页只讲一件事。

## 10. 模拟数据声明

- **模拟**：标志重捕的池塘真实鱼数、eDNA 三段序列（COI 条形码为演示模拟，真实比对需基因库）、统计抽样总体（"梦兽身高" N(160, 15²)）、8 个小实验的演示数据均为虚构/模拟数据。

- 作品不收集任何个人信息，页面运行无网络请求、无追踪；结果卡中的链接指向系官网公开页面，仅在用户点击时跳转。
